Welcome to hinnkaDistro installtion

hinnkaDistro is a minimal and lightweight linux distribution based with Arch Linux.

----------------------

👌Getting started

ℹ️This is for fresh installed Arch Linux system and must be a chroot

----------------------

👌Go with autoinstall

You can run autoinstall script like 'sh autoinstall.sh' for out-of-the-box ready script.

Follow these steps on chroot (this will apply manual install too):

'su - [USERNAME]'

ℹ️Replace "[USERNAME]" to put your user you just created.

'git clone https://github.com/81bx/hinnkaDistro'

'cd hinnkaDistro'

'sh autoinstall.sh'

Source

----------------------

👌Go with without autoinstall.sh

You can install it manually.

ℹ️You must install git on chroot because there is not installed by default

'pacman -Sy --needed git'

If installed, type 'git clone https://github.com/81bx/hinnkaDistro'

If cloned, type 'cd hinnkaDistro' and choose packages scripts like 'normalpackages.sh'

For example:

'sh normalpackages.sh && sh i3.sh && yayaur.sh'

ℹ️Note that 'i3.sh' has SDDM and NetworkManager Source (normalpackages.sh)

Source (litepackages.sh)

Source (gamingpackages.sh)

Source (i3.sh)

Source (yayaur.sh)

----------------------

Now, type 'cd airootfs' and do this (as root):

'cp -r etc / && cp -r usr /'

ℹ️Before doing next step, remove 'hinnkaDistroCLI' folder on root (/)

'rm -rf /hinnkaDistroCLI'

And then, type 'su - [USERNAME]'

ℹ️Replace "[USERNAME]" to put your user you just created.

Once you in as a user, you must clone 'hinnkaDistroCLI' again:

'git clone https://github.com/81bx/hinnkaDistroCLI'

Then type these:

'sudo mkdir ~/.config'

'cd ~/hinnkaDistroCLI/airootfs/config/'

'sudo cp -r fastfetch ~/.config'

----------------------

✅Finsh the install

🚀Once done, type 'exit' to logout, and type 'exit' again to leave chroot.

ℹ️You have finshed installing hinnkaDistro! Type 'reboot' to restart the system.
