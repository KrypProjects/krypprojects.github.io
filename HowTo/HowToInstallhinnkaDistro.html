Welcome to hinnkaDistro installation

hinnkaDistro is a minimal and lightweight linux distribution based with Arch Linux.

----------------------

👌Getting started

ℹ️This is for fresh installed Arch Linux system and must be a chroot

----------------------

👌Go with autoinstall

You can run autoinstall script like 'sh autoinstall.sh' for out-of-the-box ready script.

Follow these steps on chroot (this will apply manual install too):

'su - [USERNAME]'

ℹ️Replace "[USERNAME]" to put your user you just created.

ℹ️Also the normal autoinstall script has i3 Window Manager by default

'git clone https://github.com/81bx/hinnkaDistro'

'cd hinnkaDistro'

'sh autoinstall.sh'

ℹ️With LXQt:.

'sh autoinstall-lxqt.sh'

ℹ️With Hyprland:

'sh autoinstall-hyprland.sh'

Source (autoinstall-hyprland.sh)

Source (autoinstall-lxqt.sh)

Source (autoinstall.sh)

----------------------

👌Go with without autoinstall.sh

⚠️i3.sh has been disbaled and moved to 'litepackages.sh' and 'normalpackages.sh'

You can install it manually.

ℹ️You must install git on chroot because there is not installed by default

'pacman -Sy --needed git'

If installed, type 'git clone https://github.com/81bx/hinnkaDistro'

If cloned, type 'cd hinnkaDistro', here are these sctipts:

Source (litepackages-hyprland.sh)

Source (litepackages-lxqt.sh)

Source (litepackages.sh)

Source (normalpackages-hyprland.sh)

Source (normalpackages-lxqt.sh)

Source (normalpackages.sh)

Source (gamingpackages.sh)

Source (i3.sh) [Disabled]

Source (yayaur.sh)

If you want normal packages, type this:

'sh normalpackages.sh'

If you want lite packages, type this:

'sh litepackages.sh'

[--- OR ---]

If you want normal packages but don't want i3 Window Manager by default?, type this:

'sh normalpackages-lxqt.sh'

If you want lite packages but don't want i3 Window Manager by default?, type this:

'sh litepackages-lxqt.sh'

Same goes as Hyprland:

'sh litepackages-hyprland.sh'

ℹ️We had a LXQt version(s) if you don't want i3 Window Manager on default.

ℹ️Note that 'i3.sh' has SDDM and NetworkManager

----------------------

Now, type 'cd airootfs' and do this (as root):

'cp -r etc / && cp -r usr /'

ℹ️Before doing next step, remove 'hinnkaDistroCLI' folder on root (/)

'rm -rf /hinnkaDistroCLI'

And then, type 'su - [USERNAME]'

ℹ️Replace "[USERNAME]" to put your user you just created.

Once you in as a user, you must clone 'hinnkaDistroCLI' again:

'git clone https://github.com/81bx/hinnkaDistroCLI'

Then type these:

'sudo mkdir ~/.config'

'cd ~/hinnkaDistroCLI/airootfs/config/'

'sudo cp -r fastfetch ~/.config'

----------------------

✅Finsh the install

🚀Once done, type 'exit' to logout, and type 'exit' again to leave chroot.

ℹ️You have finshed installing hinnkaDistro! Type 'reboot' to restart the system.
